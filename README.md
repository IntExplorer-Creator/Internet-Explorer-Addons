# Internet-Explorer-Addons

Набор инструментов, твиков SCHANNEL (TLS 1.3, TLS 1.2), актуальных сертификатов безопасности и Python-шлюз для старых браузеров.

Набор инструментов и реестровых конфигураций для восстановления совместимости устаревших браузеров и операционных систем с современным веб-интерфейсом (HTTPS/TLS 1.2+).

## 📂 Содержимое репозитория

* **`gateway.py`** — Двухрежимный локальный прокси-шлюз на Python.
  * **HTTP:** Автоматическая подмена User-Agent на современный Firefox 153.
  * **HTTPS:** Высокоскоростное TCP-туннелирование (`CONNECT`).
  * **Binding:** `0.0.0.0:8080` (подходит для работы с виртуалками).
* **`----User-Agent List----.md`** — База актуальных идентификаторов браузеров.
* **`tls12.reg`** — Включение поддержки TLS 1.2 в SCHANNEL и системных настройках.
* **`tls13.reg`** — Экспериментальный твик для включения TLS 1.3.
* **`WindowsRoot.sst`** — Актуальные корневые сертификаты безопасности.
* **`WindowsIntermediate.sst`** — Актуальные промежуточные сертификаты безопасности.
* **`readme.txt`** — Локальная текстовая инструкция.

## 🚀 Быстрый запуск

1. **Сертификаты:** Импортируйте `WindowsRoot.sst` и `WindowsIntermediate.sst` в соответствующие системные хранилища доверенных сертификатов (через `certmgr.msc`).
2. **Реестр:** Примените `tls12.reg` двойным кликом (подтвердите слияние реестра). При необходимости включите `tls13.reg`.
3. **Шлюз:** Запустите шлюз командой: `python gateway.py`
4. **Прокси:** Настройте прокси в браузере / ОС на `127.0.0.1:8080` (или IP хоста в ВМ).
