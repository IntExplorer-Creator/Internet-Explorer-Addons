=======================================================================
    IntExplorerAddons & SCHANNEL Protocols Setup Guide
=======================================================================

[ ОПИСАНИЕ / DESCRIPTION ]
Набор компонентов и реестровых твиков для обеспечения работы 
устаревших браузеров на современных веб-ресурсах.

[ СОДЕРЖИМОЕ ПАПКИ ]
1. gateway.py — Локальный прокси-шлюз на Python (порт 8080).
2. tls12.reg — Активация TLS 1.2 в SCHANNEL и Internet Settings (Стабильно).
3. tls13.reg — Активация TLS 1.3 в SCHANNEL и Internet Settings (Экспериментально).
4. readme.txt — Данное руководство по установке и настройке.

[ ОСОБЕННОСТИ РАБОТЫ GATEWAY.PY ]
- При HTTP-запросах: шлюз автоматически подменяет User-Agent 
  на современный (Firefox 153) для обхода блокировок старых браузеров.
- При HTTPS-запросах: шлюз работает в режиме проходного TCP-туннеля 
  (CONNECT), передавая шифрованный трафик напрямую. За шифрование 
  и User-Agent в HTTPS отвечает сама система и файл `tls12.reg`.
- Шлюз запущен на `0.0.0.0:8080`, что позволяет использовать его 
  как прокси для виртуальных машин (через IP-адрес хоста).

[ ИНСТРУКЦИЯ ПО УСТАНОВКЕ ]
1. Запустите `tls12.reg` и подтвердите слияние с реестром (Да/Yes).
2. (Опционально) Запустите `tls13.reg`, если требуется экспериментальный TLS 1.3.
3. Запустите `gateway.py` через Python 3.x и пропишите в настройках 
   браузера / системы прокси: `127.0.0.1:8080` (или IP хоста для ВМ).
4. Перезагрузите браузер.

[ ВАЖНЫЕ ПРИМЕЧАНИЯ ]
- ВНИМАНИЕ: Файл `tls13.reg` является ЭКСПЕРИМЕНТАЛЬНЫМ!
