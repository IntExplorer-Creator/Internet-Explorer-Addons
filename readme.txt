===============================================================
   IntExplorerAddons & SCHANNEL Protocols Setup Guide
===============================================================

[ ОПИСАНИЕ / DESCRIPTION ]
Набор компонентов, сертификатов и реестровых твиков для обеспечения работы 
устаревших браузеров и систем на современных веб-ресурсах.

[ СОДЕРЖИМОЕ ПАПКИ ]
1. gateway.py — Локальный прокси-шлюз на Python (порт 8080).
2. ----User-Agent List----.md — База актуальных идентификаторов браузеров.
3. tls12.reg — Активация TLS 1.2 в SCHANNEL и Internet Settings (Стабильно).
4. tls13.reg — Активация TLS 1.3 в SCHANNEL и Internet Settings (Экспериментально).
5. WindowsRoot.sst — Актуальные корневые сертификаты безопасности.
6. WindowsIntermediate.sst — Актуальные промежуточные сертификаты безопасности.
7. readme.txt — Данное руководство по установке и настройке.

[ ОСОБЕННОСТИ РАБОТЫ GATEWAY.PY ]
- При HTTP-запросах: шлюз автоматически подменяет User-Agent на современный (Firefox 153) для обхода ограничений старого софта.
- При HTTPS-запросах: шлюз работает в режиме проходного TCP-туннеля (CONNECT), передавая зашифрованный трафик напрямую. За шифрование и TLS отвечает сама система (благодаря `tls12.reg` и сертификатам).
- Шлюз запущен на `0.0.0.0:8080`, что позволяет использовать его как прокси для виртуальных машин (через IP-адрес хоста).

[ ИНСТРУКЦИЯ ПО УСТАНОВКЕ ]
1. Сертификаты безопасности:
   - Импортируйте `WindowsRoot.sst` в хранилище «Доверенные корневые центры сертификации» (Trusted Root Certification Authorities).
   - Импортируйте `WindowsIntermediate.sst` в хранилище «Промежуточные центры сертификации» (Intermediate Certification Authorities).
   (Импорт можно выполнить через MMC-оснастку «Сертификаты» -> certmgr.msc).

2. Патчи реестра:
   - Запустите `tls12.reg` и подтвердите слияние с реестром (Да/Yes).
   - (Опционально) Запустите `tls13.reg`, если требуется экспериментальный TLS 1.3.

3. Настройка прокси:
   - Запустите `gateway.py` через Python 3.x.
   - Пропишите в настройках браузера или системного прокси: `127.0.0.1:8080` (или IP хоста, если вы на виртуальной машине).

4. Перезагрузите браузер.

[ ВАЖНЫЕ ПРИМЕЧАНИЯ ]
- Внимание: файл `tls13.reg` является ЭКСПЕРИМЕНТАЛЬНЫМ и на некоторых старых сборках Windows может работать нестабильно.
